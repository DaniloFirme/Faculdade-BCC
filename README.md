## 🔄 Como atualizar este controle

1. Quando uma DP for aprovada, altere o estado para **✅ Aprovada** neste README, na página do respectivo período e em [`dados/disciplinas.json`](dados/disciplinas.json).
2. Quando chegar a um novo período, troque a indicação de período atual no cabeçalho e reveja a classificação das matérias ainda pendentes.
3. Novas disciplinas, repositórios e trabalhos podem ser adicionados às páginas de cada período.
4. Confira sempre o histórico oficial da universidade; **este repositório é um controle pessoal**.
